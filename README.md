# Simple Interest Calculator

A lightweight, terminal-based Bash script designed to calculate simple interest quickly based on user inputs.

## Description
This project satisfies the requirements for the Introduction to Git and GitHub final assignment. It contains a simple shell script (`simple-interest.sh`) that computes the interest accrued over a specific period given a principal amount, a annual interest rate, and the time duration in years.

## Formula Used
The calculator computes interest using the standard mathematical formula:
Simple Interest = (Principal * Rate of Interest * Time Period) / 100

## Input Fields
* **Principal:** The initial amount of money invested or borrowed.
* **Rate of Interest:** The annual interest rate percentage.
* **Time Period:** The duration of the investment or loan in years.

## How to Run
1. Make the script executable:
   ```bash
   chmod +x simple-interest.sh
   ```
2. Execute the script:
   ```bash
   ./simple-interest.sh
   ```
